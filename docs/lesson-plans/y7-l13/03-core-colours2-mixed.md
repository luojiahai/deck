# Lesson 13.3: Core Colours 2 (颜色橙紫棕绿灰) + Text 2 Dialogue

**Year Level:** Year 7
**Unit:** Unit 5 — Colours, Clothing & Body
**Lesson:** Lesson 13 — Colours 颜色 | Lesson 3 of 8
**Duration:** 50 minutes

## Learning Intention
We are learning five more colours in Chinese and performing the Text 2 dialogue about colour preferences.

## Success Criteria
- I can say five more colours: 橙色, 紫色, 棕色, 绿色, 灰色 (能说五个新颜色)
- I can say the word for "colour" on its own: 颜色 (能说"颜色")
- I can perform the Text 2 dialogue with a partner (能和同伴表演课文二)

## Materials Needed
- Projector
- Mini whiteboards + markers
- Students' exercise books and pens

---

## Lesson Sequence

### Review (0–8 min)

**What:** Lesson 2's question pattern (你喜欢什么颜色？/ 你喜欢……吗？) using Lesson 1's six colours.

**How:** Pair dialogue — students do Lesson 2's Find-Someone-Who dialogue from memory with a partner (30 seconds each direction), then swap roles. Cold call one pair to perform for the class.

**Connection:** "上节课我们学会了怎么问颜色。今天我们要学五个新颜色，然后用课文二的对话来练习问答。"

---

### Learning Intention & Success Criteria (8–10 min)

Project and read aloud together. Keep visible for the lesson.

---

### I Do (10–20 min)

#### New Vocabulary

Display each row on the projector: 汉字 → pinyin → English. Model pronunciation twice, class repeats twice.

| 汉字 | 拼音 | English |
|---|---|---|
| 颜(顏) | yán | colour |
| 颜色 | yánsè | colour |
| 橙 | chéng | orange |
| 橙色 | chéngsè | orange colour |
| 紫 | zǐ | purple |
| 紫色 | zǐsè | purple |
| 棕 | zōng | brown |
| 棕色 | zōngsè | brown |
| 绿(綠) | lǜ | green |
| 绿色 | lǜsè | green |
| 灰 | huī | grey |
| 灰色 | huīsè | grey |

*Point out:* 颜色 on its own means "colour" (the general noun) — it's what you ask about: 你喜欢什么颜色？literally "you like what colour?"

#### Key Text: Text 2 Dialogue (p.100, CD T63)

> A: 你喜欢什么颜色？
> B: 我喜欢橙色、紫色、棕色和绿色。
> A: 你喜欢灰色吗？
> B: 不喜欢。
> A: 我也不喜欢。

Read aloud once (teacher only), then choral read together with both roles. Ask:
- B喜欢哪几个颜色？(橙色、紫色、棕色、绿色)
- A和B都喜欢灰色吗？(都不喜欢 — both dislike it)

#### CFU Checkpoints

- **(Gesture)** "Thumbs up if 绿色 means green."
- **(Mini whiteboards)** "Write 'purple' in Chinese."
- **(Cold call)** "Sam, how do you say 'brown' in Chinese?" → "Mia, 'orange' 呢？"

---

### Flexible Practice (20–43 min)

This lesson mixes one speaking activity, one writing activity, and one game — moving from We Do to You Do.

#### Activity 1: Dialogue Performance — We Do → You Do (10 min) | 20–30 min

**What:** In pairs, students perform the Text 2 dialogue, then swap it out — Student B must list a *different* combination of colours than the textbook (using any of the 11 colours learned so far across Lessons 1–3), and Student A asks about a different colour for the yes/no question.

**How:**
- Model the swapped version once with a volunteer: "你喜欢什么颜色？" "我喜欢黑色、红色和绿色。" "你喜欢棕色吗？" "不喜欢。" "我也不喜欢。"
- Pairs rehearse (2 min), then perform for a neighbouring pair.

**OTR:** Every student speaks both roles (swap after first performance).

- **Scaffold:** Colour word bank (all 11 words with pinyin) on the board throughout.
- **Extension:** Add a third exchange of their own invention using 我也喜欢 (agreement) instead of disagreement.

---

#### Activity 2: New Word Copying + Sentence Writing — You Do (8 min) | 30–38 min

**What:** Students copy the six new words into their books (workbook Ex.15 style), then write 2 original sentences: one using 我喜欢 with two of today's colours, one using 我不喜欢 with one.

**How:** Project stroke order for 颜, 橙, 紫, 棕, 绿, 灰. Students copy each 3 times, then write their two sentences independently. Cold call 2–3 students to read a sentence aloud.

**OTR:** All students complete the copying and both sentences; cold call samples the room.

- **Scaffold:** Sentence frame: 我(不)喜欢____和____。
- **Extension:** Students write a third sentence combining all 11 colours learned so far into one list using 、 correctly (comma convention from Text 2).

---

#### Game: Slap the Board — All 11 Colours (5 min) | 38–43 min

**How to play:** All 11 colour flashcards (Lessons 1 + 3) on the board. Two students race to slap the card as the teacher calls out the English name. Winner stays up.

**What language it practises:** Rapid recall across the full colour set so far.

**Setup needed:** Flashcards or projected grid.

- **Scaffold:** Pinyin visible under each character.
- **Extension:** Winner must use the colour in a full sentence before the next round.

---

### Plenary (43–50 min)

- **Revisit Success Criteria:** Read aloud; student volunteer confirms each was achieved.

- **Self-assessment:** Thumbs 👍/😐/👎 against each criterion.

- **Exit ticket (mini whiteboards, 2 min):** Students write one sentence:
  > 我喜欢____、____和____。
  using three colours from today's lesson (not Lesson 1's colours).

- **Preview:** "下一课，我们要把颜色和交通工具放在一起——比如'黑色的火车'！"
