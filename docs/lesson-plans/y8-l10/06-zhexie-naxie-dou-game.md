# Lesson 10.6: 这些/那些/一些 + 都 Review + Full Text 2 Dialogue

**Year Level:** Year 8
**Unit:** Unit 4 — 蔬菜、水果 (Vegetables and Fruits)
**Lesson:** Lesson 10 — Vegetables and Fruits 蔬菜、水果 | Lesson 6 of 8
**Duration:** 50 minutes

## Learning Intention
We are learning to use 这些 (these), 那些 (those), and 一些 (some) to talk about groups of things, and to revisit 都 (all/both) from Unit 3.

## Success Criteria
- I can use 这些/那些/一些 correctly to describe groups of fruit or objects
- I can use …，都… to say I like/dislike everything in a list (苹果、香蕉、橘子，我都喜欢吃)
- I can read and understand the full Text 2 dialogue about fruit
- I can recall this unit's radicals from memory in a dictation game

## Materials Needed
- Projector (Text 2 dialogue slide, radical grid image from p. 97)
- Mini whiteboards + markers
- Printed copy of Text 2 dialogue (p. 95) for choral/paired reading
- Object/picture sets for demonstrative practice (small groups of fruit pictures placed "near" vs "far" on desks)
- Blank 6×5 grid template (one per team) for the radical dictation game

---

## Lesson Sequence

### Review (0–8 min)
**What:** Fruit vocabulary from Lesson 5
**How:** Flashcard rapid fire — show 8 fruit words on the projector, class says pinyin + English chorally; then Bingo grid with fruit words for 3 minutes.
**Connection:** "You can now name lots of fruits. Today we learn how to talk about groups of them — 'these apples', 'those bananas', 'some grapes' — and we revisit 都, which you used back in Unit 3 for hobbies. Then we'll read the full fruit conversation and play a big radical review game."

### Learning Intention & Success Criteria (8–10 min)
Display on projector. Hold up a small group of objects close to you and a group far away; ask "How would English speakers point to these two groups differently?" (these vs those) — bridge to Chinese.

### I Do (10–20 min)
#### Grammar Focus
| 汉字 | 拼音 | English |
|---|---|---|
| 这些 | zhèxiē | these |
| 那些 | nàxiē | those |
| 一些 | yìxiē | some |
| 都 | dōu | all; both (revisit from Unit 3) |

Present the three demonstratives side by side with a simple diagram: 这些 (near + plural), 那些 (far + plural), 一些 (unspecified amount, "some"). Contrast with the singular forms 这个/那个 if students remember them from earlier study.

#### Key Sentence Pattern
> 苹果、香蕉、橘子，我都喜欢吃。(Apples, bananas, tangerines — I like them all.)
> 我不喜欢吃这些水果。我喜欢吃西瓜和梨。(I don't like these fruits. I like watermelon and pears.)

Model 2–3 examples, thinking aloud: "To say 'I don't like these vegetables', I need 我不喜欢吃 + 这些 + 蔬菜 → 我不喜欢吃这些蔬菜。" Second example: 那些杂志，我都不喜欢看。 Insert a silly one: 这些苹果都是我的，一个也不给你！(wait for reactions).

#### CFU Checkpoints
- "What does 那些 mean? Thumbs up if you know."
- "Where does 都 go in the sentence — before or after the verb?" (before)
- "How would I say 'some fruits'? Write it on your whiteboard."

#### Text / Dialogue
**Text 2 (p. 95, CD Track 49)**
> 你喜欢吃什么水果？苹果、香蕉、橘子，我都喜欢吃。我不喜欢吃这些水果。我喜欢吃西瓜和梨。你每天都吃水果吗？我每天都吃两三种水果。

Read aloud, students follow with the printed copy. Read together (choral), then in pairs taking A/B roles. Comprehension questions: (1) Which 3 fruits does the first line mention? (2) Does the second speaker like those fruits? (3) How many kinds of fruit does the second speaker eat every day? (flag 两三种 — we'll unpack this fully next lesson.)

### Flexible Practice (20–43 min)

#### Activity 1: Near/Far Object Sort — We Do (7 min)
Place two groups of fruit-picture cards on desks — one "near" cluster, one "far" cluster. Students practise pointing and saying 这些是苹果 / 那些是香蕉, then describe a "some" subset with 一些.
- **Scaffold:** Sentence frame on the board: 这些/那些/一些 + 是/喜欢吃 + noun.
- **Extension:** Students combine with 都: 这些水果，我都喜欢吃. Fluent speakers then translate 2 sentences from Workbook Ex.15 into English (我不喜欢吃这些水果。你们有西瓜吗？/ 那些画儿我都不喜欢。你们有国画儿吗？).
- **OTR:** Every student says at least one sentence in pairs.

#### Activity 2: Group the Words (Workbook Ex.10) — We Do → You Do (7 min)
Students sort 15 words (黄瓜/青菜/苹果/游泳/香蕉/西红柿/橘子/南瓜/冬瓜/土豆/生菜/菜花儿/西瓜/梨/篮球/跑步/网球/足球) into 3 columns: vegetables / fruits / sports.
- **Scaffold:** First word done as an example (黄瓜 → vegetables).
- **Extension:** Students write one 都-sentence per column (e.g. 黄瓜、青菜、土豆，都是蔬菜).
- **OTR:** Whiteboard/worksheet check with a partner before whole-class reveal.

#### Game: Radical Dictation Grid (Textbook Act.12) — You Do (9 min)
Project the textbook's cumulative radical grid (p. 97, 30 radicals in a 6×5 layout, covering Unit 3 and Unit 4 radicals learned so far: 寸米足木斗力/青立矢皿巾水/舌瓜羊禾弓田/自己包止士豆/夕心目方平土/角页食果欠石) for two minutes so teams can memorise positions. Hide it, then dictate radicals one at a time by pinyin/meaning; in teams, students write each into the correct grid square from memory. Most correct squares wins.
- **Setup needed:** Radical grid displayed on the projector, blank 6×5 grid template per team.

### Plenary (43–50 min)
- **Revisit Success Criteria:** Student volunteer reads each criterion aloud; class responds with the target structure.
- **Self-assessment:** Thumbs up / sideways / down against each of the 4 criteria.
- **Exit ticket:** "Write one sentence using 这些 or 那些 about food."
- **Preview:** "Next lesson: the measure word 种 (kind/type) and how to say ranges like 'two or three kinds' — 两三种!"
