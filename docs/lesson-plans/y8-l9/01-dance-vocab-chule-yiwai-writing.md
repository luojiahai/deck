# Lesson 9.1: Dance Vocabulary + 除了……以外

**Year Level:** Year 8
**Unit:** Unit 3 — 爱好 (Hobbies)
**Lesson:** Lesson 9 — Hobby (3): Dance 舞蹈 | Lesson 1 of 8
**Duration:** 50 minutes

## Learning Intention
We are learning to talk about a new hobby — dance — and use 除了……以外 to say "besides X, I also like Y."

## Success Criteria
- I can say 舞蹈, 跳舞, 从, 开始 in Chinese (用拼音说出新词汇)
- I can use 除了……以外 to list an extra hobby (除了音乐以外，我还喜欢舞蹈)
- I can write and recognise the characters 平, 土, 角, 页
- I can recognise this unit's key radicals from dictation

## Materials Needed
- Projector (vocab slides: 汉字 + pinyin + English)
- Mini whiteboards + markers
- Printed vocab-tracing worksheet (new words below)
- Printed character-writing worksheet (平 / 土 / 角 / 页)
- Word-card set for 除了……以外 sentence building (one set per pair)
- Textbook radical grid, p.81 (for the dictation game); blank 5×5 grid templates (one per team)

---

## Lesson Sequence

### Review (0–8 min)
**What:** Unit 3 so far — L7 music vocab (听音乐, 弹钢琴, 唱歌) and L8 sports vocab/grammar (跟……一起, 不太, 差不多/经常/常常)
**How:** Flashcard rapid fire on the projector (L7 and L8 words, class says pinyin + English chorally), then teacher says an English hobby sentence starter ("I like swimming with my friend") and students write the Chinese on mini whiteboards, hold up on three.
**Connection:** "You've now learned two hobby topics — music and sport. Today we start our third and final hobby topic in this unit: dance 舞蹈 — and a new phrase for listing an *extra* hobby on top of the ones you already know: 除了……以外."

### Learning Intention & Success Criteria (8–10 min)
Display on projector. Read the learning intention aloud together. For each success criterion, ask "hands up if you've seen this word before" — 舞 and 跳 may be familiar from unrelated contexts (e.g. 跳绳).

### I Do (10–20 min)
#### New Vocabulary
| 汉字 | 拼音 | English |
|---|---|---|
| 除 | chú | besides |
| 除了……以外 | chúle…yǐwài | besides; apart from |
| 舞 | wǔ | dance |
| 蹈 | dǎo | skip |
| 舞蹈 | wǔdǎo | dance (formal noun) |
| 跳 | tiào | jump |
| 跳舞 | tiàowǔ | dance |
| 从 | cóng | from |
| 始 | shǐ | begin |
| 开始 | kāishǐ | start; begin |

Introduce each word: 汉字 → pinyin → English, class repeats twice (choral). Keep pinyin visible throughout. Point out that 舞蹈 (the noun "dance") and 跳舞 (the verb phrase "to dance") share the character 舞 — one is a thing, one is an action, and 跳 ("jump") is the clue that dancing involves movement.

#### Key Sentence Pattern
> 除了X以外，我还喜欢Y。 (Besides X, I also like Y.)

Model 3 examples, thinking aloud: "To say 'besides music, I also like dance', I need 除了 + 音乐 + 以外，我还喜欢 + 舞蹈 → 除了音乐以外，我还喜欢舞蹈。" Second example: 除了游泳以外，我还喜欢打网球。 Insert a silly one: 除了吃饭以外，我还喜欢吃饭！(wait for reactions).

#### CFU Checkpoints
- "What does 舞蹈 mean? Thumbs up if you know."
- "How would I say 'besides swimming, I also like singing'? Write the frame on your whiteboard, blanks OK."
- "Error check: 我除了音乐以外还喜欢舞蹈以外。What's wrong?" (check: 以外 only appears once, right after the first item)

### Flexible Practice (20–43 min)

#### Activity 1: Vocab Tracing & Character Writing Worksheet — We Do (8 min)
Students trace each of the 10 new words/phrases three times, then trace and copy the 4 simple characters 平 / 土 / 角 / 页 on the character worksheet.
- **Scaffold:** Pinyin printed above every character on the tracing lines; stroke-order arrows shown for the 4 simple characters.
- **Extension:** After tracing, students cover the pinyin/English columns and self-quiz by writing meanings from memory; for 平/土/角/页 they also write one other character they know that shares the same radical, if any.
- **OTR:** Every student writes every word — 100% response rate by design.

#### Activity 2: 除了……以外 Sentence-Building with Word Cards — We Do → You Do (8 min)
In pairs, students arrange word cards (除了 / [hobby A] / 以外 / 我还喜欢 / [hobby B]) into correct sentences, then copy 3 correct sentences into their books, swapping in different hobby pairs each time.
- **Scaffold:** Word cards colour-coded by slot (除了…以外 = one colour, hobby words = another) so the frame is visually obvious.
- **Extension:** Students write one sentence using a hobby not on the cards (e.g. from L7/L8 vocabulary) and one sentence about a family member ("我爸爸除了……以外，还喜欢……").
- **OTR:** Cold call 4–5 pairs to read one sentence aloud before the game.

#### Game: Radical Dictation Grid — Act.1 Style (7 min)
Project the textbook's "Learn the Radicals" grid (p.81, 25 radicals in a 5×5 layout) for one minute so students can memorise positions. Hide it, then dictate radicals one at a time by pinyin/meaning; in teams, students write each into the correct grid square from memory. Most correct squares after 15 radicals wins.
- **Setup needed:** Textbook radical grid (p.81) displayed on the projector, blank 5×5 grid template per team.

### Plenary (43–50 min)
- **Revisit Success Criteria:** Student volunteer reads each criterion aloud; class responds with the target word/sentence.
- **Self-assessment:** Thumbs up / sideways / down against each of the 3 criteria.
- **Exit ticket:** "Write one sentence about your own hobbies using 除了……以外."
- **Preview:** "Next lesson we'll practise 除了……以外 some more — writing longer sentences and describing a busy park scene."
