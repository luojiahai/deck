L2 · 比 COMPARISON

Game · 比字句拼句子 · 40–43 min

GAME

40–43 min

Pairs Race · Whiteboards

比字句拼句子 · Sentence Jumble

How to Play

1

Project 2 sets of scrambled words for a 比 sentence.

2

In pairs, students race to reorder the words into a correct 比 sentence on their whiteboards.

3

First pair with the correct sentence holds it up and reads it aloud for the class to confirm.

Setup Needed

Mini whiteboards only

Practises: 比 sentence word order

Example Scrambled Set

新鲜

比

超市

菜市场

的菜

的菜

Correct Answer

菜市场的菜比超市的菜新鲜。

Scaffold

Give the sentence's English translation alongside the scrambled words.

Extension

After solving, pairs write one additional original 比 sentence using the same adjective.
