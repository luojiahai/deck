Instrument Verb Rule · 拉 vs 弹
拉 — bowed string instrument
拉小提琴 lā xiǎotíqín — "pull" the bow
弹 — keyboard / plucked instrument
弹钢琴 / 弹吉他 tán gāngqín / tán jítā — "flick / pluck"
拉 and 弹 are not interchangeable — mixing them up is a common mistake.
