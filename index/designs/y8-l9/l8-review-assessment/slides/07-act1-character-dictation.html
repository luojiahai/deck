How It Works

1️⃣
Grid displayed for 90 seconds to memorise the character in each numbered square — then hidden.
2️⃣
Teacher dictates one character at a time by pinyin or meaning (e.g. "tǔ — soil").
3️⃣
Students write it into the matching numbered square on their blank grid template.
4️⃣
Run as a team competition — most correct squares wins.
👥
Characters: 平 土 角 页 (new this unit) + 包 止 士 豆 夕 心 目 方 (review, L7–L8)
Pool of 12 characters cycled across the 25 grid squares
Scaffold
Grid stays partially visible (positions labelled with pinyin) for students who need it; teacher repeats each dictated item twice
Extension
Students also write one word that uses each dictated character as part of a compound, where they know one
OTR
Every student writes every dictated item — team format keeps engagement high
