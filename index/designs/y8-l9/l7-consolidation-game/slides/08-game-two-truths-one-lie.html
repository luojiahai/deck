L7 · CONSOLIDATION Game · Two Truths, One Lie
Game
⏱ 7 min
Small Groups
两真一假 · Two Truths, One Lie
Each student says 3 hobby sentences using 3 different L9 patterns — the group votes on the lie
Example Round
1除了游泳以外，我还喜欢舞蹈。
2我从三岁开始拉小提琴。
3我在学校打篮球呢。
Which one is the lie? 🤔

How to Play

1️⃣
In small groups, each student says 3 sentences about their hobbies, each using a different one of the 5 L9 grammar patterns.
2️⃣
Two sentences are true, one is a lie.
3️⃣
The group listens and votes on which sentence is the lie — the student then reveals the answer.
🛠️
Setup: none beyond the 5-pattern chart
The recap chart from earlier stays visible for reference — no extra materials needed
