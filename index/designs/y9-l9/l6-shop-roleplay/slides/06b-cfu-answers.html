Mini Whiteboards — write the price "15 块 5 毛"

✅ 十五块五毛

Number before 块 (yuan), then number before 毛 (jiao) — no 和 or 零 needed between them.

Cold Call — how to ask "how much is this notebook"

✅ 这本笔记本多少钱？

Measure word 本 (for bound items) + item + 多少钱？ — same structure as 一本汉语课本多少钱？
