We Do

Instructions (based on Act. 6, p.84)

  1. Teacher (seller) and a student volunteer (buyer) perform the full shop dialogue using the projected sample pattern
  2. Items come from the vocabulary lists (Lessons 1, 4, 6)
  3. Perform 2 rounds — teacher highlights the price-answer structure (X块Y毛) on the projector each time
  4. Class observes and notes the pattern, then chorally repeats each line once

买家你好！我想买一支钢笔。

卖家好的，给你。

买家一支钢笔多少钱？

卖家二十五块。
