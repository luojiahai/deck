答案 · CFU Checkpoints

1

Gesture Check — which is correct, "一支铅笔" or "一个铅笔"?

✅ 一支铅笔

个 → 支  |  铅笔 is a long, thin held item, so it takes 支.

2

Cold Call — fill the measure word for 练习本 and 尺子

✅ 一本练习本  ·  一把尺子

练习本 is a book-type item → 本  |  尺子 has a handle → 把.

3

Choral Error Correction — spot the mistake in: 我有一个课本。

✅ 我有一本课本。

个 → 本  |  课本 is a book-type item, so it takes 本, not the default 个.
