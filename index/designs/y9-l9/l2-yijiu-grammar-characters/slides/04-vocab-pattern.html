10–20 min · I Do

生词 · 句型一……就……

进

jìn

enter

看见

kànjiàn

see

Structure

Subject + 一 + action 1 + 就 + action 2

"As soon as action 1 happens, action 2 happens."

Modelled Examples · 例子 (teacher reads aloud, class repeats)

Example 1

你一进校门就能看见图书馆。

As soon as you enter the school gate, you can see the library.

Example 2

我一到家就吃饭。

As soon as I get home, I eat.

Silly Example — wait for reaction!

老师一进教室，学生就睡觉！😄

我进校门就能看见……以后

→

我一进校门就能看见……。

Common error: "一……就……"包住两个动作，不可以只用"就"，也不可以放在句子最后。
