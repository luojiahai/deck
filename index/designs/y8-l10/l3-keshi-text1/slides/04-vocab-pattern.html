💡

可是 vs 但是

Both mean "but" — 可是 is a little more conversational, but interchangeable in this context. Compare 但是 from Unit 3, Lesson 8.

How to contrast a like/dislike with an obligation

我不(太)喜欢 X

可是

我应该 Y

"I don't (really) like X. But I should Y."

我不喜欢做作业，可是我应该做作业。

I don't like doing homework, but I should do it.

我不太喜欢运动，可是我每天跑步。

I don't really like sport, but I run every day.

我非常喜欢吃土豆，可是妈妈只给我吃一个！silly example

I really like eating potatoes, but mum only lets me eat one!
