Game · 排句子 Sentence Jumble

Pairs · one envelope each · 8 minutes

1

Rebuild each of the six jumbled sentences and write it down.

2

All six contain 应该 or a list closed with 等等.

3

First pair with all six correct wins.

我们 / 吃 / 每天 / 水果 / 应该。

说 / 妈妈 / 应该 / 我 / 每天 / 吃 / 蔬菜。

非常 / 我 / 吃 / 喜欢 / 青菜。

等等 / 我 / 喜欢 / 吃 / 黄瓜、土豆、生菜。

不 / 一边 / 应该 / 听音乐 / 你 / 一边 / 做作业。

Extension · 加油题

Strips face down — you may only turn over three at a time, so the rest has to be held in memory. Then cut up two sentences of your own and swap with the next pair.
