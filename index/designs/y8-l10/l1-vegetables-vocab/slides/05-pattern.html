关键句型 · Key Sentence Pattern

How to say you like eating vegetables — and which ones

你喜欢吃蔬菜吗？

→

我非常喜欢吃。

"Do you like eating vegetables? I like it very much."

你喜欢吃什么蔬菜？

→

我喜欢吃X……

"What vegetables do you like? I like eating X..."

我非常喜欢吃西红柿。

I really like eating tomatoes.

我不太喜欢吃生菜。

I don't really like eating lettuce.

我非常喜欢吃土豆、土豆、土豆！silly example

I really like eating potato, potato, potato!

非常 comes right before 喜欢 — never between 喜欢 and 吃.
