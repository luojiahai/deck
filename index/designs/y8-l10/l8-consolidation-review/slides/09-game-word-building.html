How to Play

1️⃣

Grid projected or printed one per team — 20 base characters, each with a blank.

2️⃣

Teams add one character to each base to form a valid two-character word (e.g. 黄瓜, 电脑).

3️⃣

Write the character if known, or pinyin if not — both count as attempts.

🏆

Most correctly completed items after time's up wins.

🗂️

Setup Needed

Grid projected or printed per team; whiteboard for teams to write their answers

Grid drawn from the textbook's own word-building set, Act.17 — bases mix Unit 3 and Unit 4 characters, so every student has an entry point.
