Learning Intention · 学习目标

We are learning to write about the noises we hear from our neighbours, and say how loudly something is done using V + 得 + 形容词。

Success Criteria · 我能……

1

I can say what I hear, using 听见 + a clause

能说我听见什么：我听见有人在房间里跑步

2

I can say how something is done

能说做得怎么样：电视机开得很响

3

I can use 半夜 and 哭 in a written sentence

能在句子里用上「半夜」和「哭」

4

I can write four sentences without looking at the board

不看屏幕，也能写出四句
