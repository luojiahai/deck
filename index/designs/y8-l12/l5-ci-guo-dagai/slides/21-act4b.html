Activity 4 · 写四句 · Whiteboards up together

WHITEBOARDS · 4 MIN

Four sentences, one per tense, each with a different activity.

Hold them all up at once so the two usual errors show:

✗ 我下个周末去北京了。　　✗ 我正在看电视。

Extension · 加油题

Write all four about the same activity, so the set reads as a story — and every sentence must carry a 次 or a 大概.

我上个月去过一次上海饭店，我每个星期都想去，我正在看他们的菜单呢，我下个星期会再去一次。
