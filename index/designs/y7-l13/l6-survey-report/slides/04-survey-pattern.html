Key Sentence Pattern · Reporting Results

个人喜欢。

Textbook worked example (p.101)

Teacher projects and reads aloud, then class repeats together.

Modelled mock result set

十个人喜欢红色，八个人喜欢蓝色，两个人喜欢灰色。

Word order: the number comes first, then 个人喜欢, then the colour.
