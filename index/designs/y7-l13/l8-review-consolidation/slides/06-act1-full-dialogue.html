20–30 min · Activity 1 — Full Combined Dialogue

综合对话 · Build & Perform

1

A "what colour" question

2

A yes/no question

3

≥1 colour+noun description

4

≥1 use of 也

Model once more with a volunteer — point out each of the 4 elements as it occurs

A: 你喜欢什么颜色？B: 我喜欢蓝色和绿色。你呢？A: 我喜欢黑色和白色，不喜欢紫色。B: 我也不喜欢紫色。你喜欢黑色的汽车吗？A: 喜欢！

Task — in pairs

Build your own version with all 4 required elements (can write key phrases on a whiteboard as a memory aid). Rehearse, then perform for another pair. Every student speaks both roles.

Scaffold

Checklist card listing the 4 required elements with a sentence frame for each.

Extension

Add a 5th element: a colour-mixing statement worked in naturally — e.g. 我喜欢橙色，因为红色加黄色是橙色。(因为 = "because")

OTR

Every student speaks both roles across the paired performance. Circulate, listening for the 4 elements.
