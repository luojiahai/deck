Activity 1

⏱ 8 min

We Do · Exercise Books

活动一 · 生字抄写

1

Project each new character with its stroke-order animation/sequence: 喜, 欢, 黑, 色, 白, 黄, 蓝, 红, 粉 (modelled on workbook Ex.2 — Copy the new words of Text 1).

2

Students trace, then copy each character 3 times in their exercise books, following stroke order.

3

Teacher circulates, checking stroke order on 喜 and 黑 in particular — both have many strokes.

Scaffold

Provide a dotted/traceable version for the first repetition of each character

Extension

Fluent speakers also write the pinyin with correct tone marks next to each character, unprompted

OTR

Every student writes all 9 characters; teacher scans books during circulation
